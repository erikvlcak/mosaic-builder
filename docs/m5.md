# M5 — Per-panel transforms + selection

Placed panels are now interactive. Click an image panel to select it, then:

- Drag inside the panel to pan the image (clamped in Cover mode so the
  gutter never bleeds through).
- Scroll-wheel to zoom about the cursor, with `zoom ≥ 1` for Contain/Cover.
- Toolbar segmented control switches **Contain / Cover / Stretch** fit per
  panel; Stretch disables pan/zoom and locks zoom at 1.
- Buttons + keys: `R` (rotate 90° CW), `H` (flip horizontal), `V` (flip
  vertical), `0` (reset transform).
- `Escape` clears both the merge selection and the selected panel.

The exporter renders through the same `drawFigure` pipeline as the editor,
so PNG output matches the editor pixel-for-pixel.

Out of scope for M5 (lands later): annotations, scale bars, TIFF metadata,
undo/redo, project save/load, properties side-panel beyond the toolbar pad.
