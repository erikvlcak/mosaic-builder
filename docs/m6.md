# M6 — Annotations + TIFF + multi-format export

The figure becomes a publication-grade scientific output. Three concerns ship
together because they are coupled by the scale-bar formula:

- **TIFF support.** Add 8/16-bit TIFFs (LZW + uncompressed). Decoded in a
  Web Worker via UTIF.js so the UI stays responsive on big files. The IFD's
  `t282/t283/t296` tags are read for auto-calibration in µm/mm; if the tags
  are missing, the panel toolbar's **Calibrate…** button opens a modal where
  the user clicks two points on the image and enters a known length.
- **Annotation layer.** Subpanel letters render automatically in row-major
  order, with per-panel `letterOverrides` and a global "Subpanel letters"
  toggle. The Annotation toolbar adds **Text**, **Arrow**, **Box**, and
  **Scale bar** tools. Letters/text/boxes/arrows live in figure-canvas
  coordinates; scale bars live on a panel and recompute their figure-pixel
  length from `lengthValue × pixelsPerUnit × (zoom × baseScale)` on every
  state change — zoom the panel 2× and the bar's pixel length doubles.
- **Multi-format export.** PNG (M2) is joined by JPEG (quality slider
  0.50–1.00), TIFF (lossless, with `XResolution`/`YResolution`/`ResolutionUnit`
  injected for ImageJ DPI recognition), and PDF (`pdf-lib` raster page sized
  to the figure's physical dimensions at 300 dpi). All four route through one
  `OffscreenCanvas` pipeline so the editor and every export remain
  pixel-WYSIWYG.

The toolbar grew an **AnnotationToolbar** (5 tools + letters checkbox) next
to PanelControls, and the single **Export PNG** button became an
**ExportMenu** dropdown. Delete/Backspace removes the selected annotation;
Escape clears the selection and resets the active tool to Select.

Out of scope for M6 (lands later): project save/load (`.mosaic`), undo/redo,
relink modal, properties side-panel beyond the toolbar pads, per-image
min/max for 16-bit TIFFs, vector PDF (M6 ships a raster PDF), 16-bit-direct
TIFF export (M6 collapses to 8-bit RGBA), physical-mode `FigureCanvas`
(in/cm/mm + DPI selectable for export — M6 hardcodes 300 dpi for TIFF + PDF).
